# Data

Place the dataset here as `dataset_heart.csv`.

- **Source:** Statlog (Heart) dataset, UCI Machine Learning Repository, downloaded from Kaggle.
- **Size:** 270 patients, 13 clinical features, 1 target (`heart disease`: 1 = absence, 2 = presence).
- **Missing values:** none.
- The data is anonymised. It was used for academic purposes only.
